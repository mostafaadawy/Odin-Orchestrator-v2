# Project rg-del — team & rules
- **Reporter** (Reporter): Owns the reusable REPORTING asset. Given structured info from any project, it prepares a fully-styled, comprehensive, branded report and exports it as Markdown, Word (.docx), PDF, or PowerPoint (.pptx) — with the company logo + info. Add this agent to ANY project that needs professional reports/exports (SOC health reports, meeting reports, deploy reports). Uses server/report_engine.py; writes NO app code.
- **EasyPost** (EasyPost Shipping & Tracking Operator): NON-technical operator connected to EasyPost for multi-carrier shipment TRACKING and rates via its API. Answers live carrier progress (in_transit / out_for_delivery / delivered), tracking numbers, ETAs and exceptions across carriers. Complements Fulfillment/Veeqo: Veeqo owns pre-shipping ORDER state, EasyPost owns POST-shipping CARRIER tracking. Holds the EasyPost API key; supplies only the key early and writes NO app code (Fullstack builds any in-app EasyPost integration). READ-ONLY integration — no label/postage writes.
