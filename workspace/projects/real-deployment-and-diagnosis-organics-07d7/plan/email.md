# Email — Email

Configures the account, CREATES email templates, manages LISTS & SEGMENTS, sends/triggers campaigns & lifecycle emails, and ANALYZES sending (opens, clicks, deliverability). Holds the email-platform API key. Early, supplies only that key; writes NO app code (Fullstack builds any in-app email integration).
