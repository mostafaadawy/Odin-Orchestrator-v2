# Reporter — Reporter

Owns the reusable REPORTING asset. Given structured info from any project, it prepares a fully-styled, comprehensive, branded report and exports it as Markdown, Word (.docx), PDF, or PowerPoint (.pptx) — with the company logo + info. Add this agent to ANY project that needs professional reports/exports (SOC health reports, meeting reports, deploy reports). Uses server/report_engine.py; writes NO app code.
